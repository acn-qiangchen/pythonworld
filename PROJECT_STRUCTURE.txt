Key Features by Component
==========================

FastAPI (email-api/)
--------------------
✅ High performance (200-500 req/s)
✅ Automatic OpenAPI documentation
✅ Native async support
✅ Lightweight (~50-80 MB)
✅ Modern Python features
✅ Perfect for APIs

Django (email-api-django/)
--------------------------
✅ Browsable API interface
✅ Built-in admin panel
✅ Django ORM ready
✅ Mature ecosystem
✅ Unit tests included
✅ Full-featured framework

Terraform (terraform-ses/)
--------------------------
✅ Email identity verification
✅ Domain verification (optional)
✅ IAM user with SES permissions
✅ Configuration set for tracking
✅ CloudWatch monitoring
✅ SNS notifications
✅ Bounce/complaint tracking

API Endpoints (Both Implementations)
====================================

GET  /api/ or /              Service information
GET  /api/health/ or /health Health check + SES stats
POST /api/v1/send-email/     Send email via AWS SES

Quick Start Commands
====================

# Deploy Infrastructure
cd terraform-ses
terraform init
terraform apply

# Deploy FastAPI
cd email-api
docker-compose up -d

# Deploy Django
cd email-api-django
docker-compose up -d

# Test API
curl http://localhost:8000/api/health/
